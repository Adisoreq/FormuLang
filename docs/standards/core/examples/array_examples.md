# Array examples

Examples of using arrays

## Examples

### Example 1

Initializing arrays

#### Formula:

```
$a1 = ARRAY(1, 2, 3)
$a2 = ARRAY("a", "b", "c")

[$a1, $a2]
```

#### Result:

```
[ [ 1, 2, 3 ], [ a, b, c ] ]
```

#### Explanation:

Arrays may be nested
