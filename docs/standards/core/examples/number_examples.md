# Number examples

Examples of using numeric values.

## Examples

### Example 1

Simple operations on integer numbers

#### Formula:

```
5 + 3
```

#### Result:

```
8
```

### Example 2

Simple operations on real numbers

#### Formula:

```
15 * 0.5
```

#### Result:

```
7.5
```

### Example 3

Using real numbers expressed with scientific notation.

#### Formula:

```
4.2E+3 * 2E-2
```

#### Result:

```
84
```

#### Explanation:

`4.2E+3` is computed as `4.2 * 10^3` and `2E-2` as `2 * 10^-2`, which gives `4200 * 0.02`

### Example 4

Various number expressions

#### Formula:

```
# Integer
$ a = -40

# Real
$ b = .8

# Scientific
$ c = 2.5e+2

# Hexadecimal
$ d = 0x2c

# Result
a * b + c * d
```

#### Result:

```
-21
```

#### Explanation:

| Variable | Literal type | Expression | Computed |
| -------- | ---------- | ------- | -------- |
| a | Integer (decimal) | `-40` | -40 |
| b | Real (shortened) | `.8` | 0.8 |
| c | Real (scientific notation) | `2.5E-1` | 0.25 |
| d | Integer (hexadecimal) | `0x2c` | 44 |
